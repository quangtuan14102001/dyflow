VideosCreator (Windows)
=======================

1. Giai nen CA THU MUC nay (khong chi copy 1 file .exe).
2. Double-click VideosCreator.exe.
3. Lan dau Windows SmartScreen co the canh bao: More info -> Run anyway.
4. Can Google Chrome hoac Microsoft Edge de tai video Douyin.
5. Video xuat nam o: %LOCALAPPDATA%\VideosCreator\output
6. OPENAI_API_KEY da kem trong file .env (cung thu muc .exe). Khong can dien.
   Muon doi key: sua .env canh exe, hoac %LOCALAPPDATA%\VideosCreator\.env
